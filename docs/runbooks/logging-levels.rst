שינוי רמות לוגים
=================
:summary: איך משנים רמות לוג בזמן ריצה, ומתי כדאי להעלות ל-DEBUG.

מתי להעלות ל-DEBUG
-------------------
- חקירת תקלה שלא ניתנת לאבחון עם ``INFO``.
- להגביל לחלון זמן קצר (דקות עד שעה) ולחזור ל-``INFO`` בסיום.

טיפ
----
- ניתן להגדיר תזכורת או Job אוטומטי שמחזיר את הרמה ל-``INFO`` אחרי X דקות.
