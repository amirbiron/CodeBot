הורדת ריפו
==========

מה בדיוק מוריד
----------------
- הורדה לפי ref (ענף/תג) ובחירה אפשרית של תיקייה ספציפית.
- נשמר בקובץ ZIP לשימוש בהמשך (כולל מטא־דאטה במידת האפשר).

הורדת תיקייה כ־ZIP
-------------------
בתפריט ``/github`` ← **📥 הורד קובץ מריפו**, נווטו לתיקייה הרצויה. בתחתית
הרשימה יופיע כפתור שמציין במפורש מה ייארז, למשל
``📦 הורד תיקייה כ־ZIP: "logo-designer"``.

.. note::
   הכפתור אורז את התיקייה שאתם **נמצאים בה**, לא את זו שמסומנת ברשימה. כדי
   להוריד תת־תיקייה, היכנסו אליה קודם.

האריזה כוללת את כל תתי־התיקיות, ומכבדת את הענף שנבחר דרך ``🌿 ref:``. גם הכפתור שאורז את הריפו כולו מוריד את הענף שנבחר, ולא תמיד את ענף ברירת המחדל.

.. _download-repo-background:

איך האריזה רצה
~~~~~~~~~~~~~~~
הבוט מוריד מ-GitHub ארכיון אחד של כל הריפו בענף שנבחר, ואורז ממנו את התיקייה. זו בקשה אחת, ולא בקשה לכל קובץ. עד 15.11.2026 כל קובץ נמשך בבקשה נפרדת, עם השהיה של ``GITHUB_API_BASE_DELAY`` לפני כל אחת, ותיקייה של כמה מאות קבצים לקחה דקות. המחיר של הדרך הנוכחית הוא שמורידים גם את מה שמחוץ לתיקייה, ולכן ריפו גדול מאוד נעצר בתקרה של גיבוי ריפו מלא (``MAX_BACKUP_BYTES``).

העבודה רצה ברקע, והבוט ממשיך לענות לכולם בזמן שהיא רצה. ההודעה שבה לחצתם הופכת לשורת התקדמות שמתעדכנת (כמה כבר ירד מ-GitHub, ואחר כך כמה קבצים נארזו), ובסוף מתחלפת במסך הבא: שאלת היעד לתיקייה, או הגיבוי עצמו לריפו המלא. GitHub לא שולח מראש את גודל הארכיון, ולכן ההתקדמות בהורדה היא בכמות שירדה ולא באחוזים.

- **אריזה אחת בכל פעם לכל משתמש.** לחיצה נוספת על הורדה בזמן שאריזה רצה מקבלת הודעה שהאריזה כבר בדרך, ולא מתחילה אריזה שנייה.
- **בכל הבוט רצות במקביל עד** ``ZIP_JOBS_MAX_CONCURRENT`` **אריזות.** מי שמגיע כשהתור מלא רואה שהוא ממתין, ומחכה עד ``ZIP_JOB_QUEUE_WAIT_SECONDS``. אחר כך הבוט מבקש לנסות שוב מאוחר יותר.
- **לאריזה יש תקרת זמן,** ``ZIP_JOB_DEADLINE_SECONDS``. הורדה איטית מזה נעצרת עם הודעה, והקבצים הזמניים נמחקים.

הקבועים מוגדרים ב-``github_menu_handler.py``, וההסבר לכל אחד מהם בהערה שמעליו.

לאן נשמר
~~~~~~~~~
אחרי האריזה הבוט שואל לאן לשמור. שום דבר אינו נשמר לפני התשובה — הקובץ ממתין
זמנית, והתוקף שלו הוא כשעה. אחרי שעברה, ייתכן שתידרש אריזה מחדש.

- **🧩 סקיל** — נשמר בדיוק כמו שהוא (byte-for-byte), בלי קובץ מטא־דאטה בתוך
  הארכיון. זה היעד המתאים כשרוצים להעלות את התיקייה כ־Skill, שכן קובץ זר בשורש
  הארכיון פוסל אותו.
- **📦 גיבוי** — מופיע ברשימת הגיבויים, ואפשר לשחזר ממנו את התיקייה לגיטהאב
  דרך הבוט. ``metadata.json`` מתווסף בשכבת האחסון, כי רשימת הגיבויים נבנית
  מקריאתו.

שם הקובץ
~~~~~~~~~
ברירת המחדל היא שם התיקייה שנארזה (למשל ``logo-designer.zip``). הבוט מציע
אותה ומאפשר לבחור שם אחר; בבחירת "שם אחר" שולחים את השם בהודעה, בלי הסיומת
``.zip``. שמות בעברית נתמכים; תווים שאינם חוקיים בשם קובץ מוחלפים במקף.

מגבלות
-------
- מגבלות גודל/כמות קבצים בהתאם להגדרות GitHub ושירות ההורדה.
- קבצים שחורגים ממגבלת הגודל לקובץ בודד מדולגים, וכך גם קבצים שמעבר לתקרת
  הכמות או הגודל הכולל של הארכיון. שני סוגי הדילוג נספרים בנפרד ומדווחים —
  גם במסך הבחירה וגם בכיתוב הקובץ. הסינון הוא לפי גודל וכמות בלבד, לא לפי
  סוג הקובץ.
- אם *כל* הקבצים דולגו, הבוט אומר זאת במפורש ולא מציע לשמור ארכיון ריק.
- קישורים סימבוליים לא נכללים בארכיון: בארכיון של GitHub התוכן שלהם הוא רק נתיב היעד, ולא הקובץ. תיקייה שיש בה רק קישורים מסתיימת בהודעה שאומרת את זה, ולא בהודעה שהנתיב לא נמצא.
- קבצים שמסומנים ב-git כקבצי הרצה נשארים כאלה בארכיון.

הודעות נפוצות
--------------
- שגיאת הרשאות (ריפו פרטי בלי טוקן) – נדרש ``GITHUB_TOKEN`` תקין.
- חריגה ממגבלות קצב – נסו שוב מאוחר יותר.
- ``⌛ הקובץ פג`` – עברה שעה מהאריזה בלי לבחור יעד; אפשר לארוז שוב.
- ``⏳ כבר מכין לך ZIP`` (``ZIP_JOB_ALREADY_RUNNING_TEXT``) – לחצתם על הורדה בזמן שאריזה קודמת שלכם עוד רצה. חכו שהיא תסתיים.
- ``⏳ אריזה אחרת רצה כרגע בבוט`` (``ZIP_JOB_QUEUE_WAIT_TEXT``) – התור מלא; האריזה שלכם תתחיל מיד כשמקום יתפנה.
- ``⌛ ההורדה מ-GitHub לקחה יותר מדי זמן`` (``ZIP_JOB_TIMEOUT_TEXT``) – האריזה עברה את תקרת הזמן ונעצרה. אפשר לנסות שוב מאוחר יותר.
