הורדת ריפו
==========
:summary: בתפריט /github ← 📥 הורד קובץ מריפו, נווטו לתיקייה הרצויה. בתחתית הרשימה יופיע כפתור שמציין במפורש מה ייארז, למשל 📦 הורד תיקייה כ־ZIP: "logo-designer".

מה בדיוק מוריד
----------------
- הורדה לפי ref (ענף/תג) ובחירה אפשרית של תיקייה ספציפית.
- נשמר בקובץ ZIP לשימוש בהמשך (כולל מטא־דאטה במידת האפשר).

הורדת תיקייה כ־ZIP
-------------------
בתפריט ``/github`` ← **📥 הורד קובץ מריפו**, נווטו לתיקייה הרצויה. בתחתית
הרשימה יופיע כפתור שמציין במפורש מה ייארז, למשל
``📦 הורד תיקייה כ־ZIP: "logo-designer"``.

.. note::
   הכפתור אורז את התיקייה שאתם **נמצאים בה**, לא את זו שמסומנת ברשימה. כדי
   להוריד תת־תיקייה, היכנסו אליה קודם.

האריזה כוללת את כל תתי־התיקיות, ומכבדת את הענף שנבחר דרך ``🌿 ref:``.

לאן נשמר
~~~~~~~~~
אחרי האריזה הבוט שואל לאן לשמור. שום דבר אינו נשמר לפני התשובה — הקובץ ממתין
זמנית, והתוקף שלו הוא כשעה. אחרי שעברה, ייתכן שתידרש אריזה מחדש.

- **🧩 סקיל** — נשמר בדיוק כמו שהוא (byte-for-byte), בלי קובץ מטא־דאטה בתוך
  הארכיון. זה היעד המתאים כשרוצים להעלות את התיקייה כ־Skill, שכן קובץ זר בשורש
  הארכיון פוסל אותו.
- **📦 גיבוי** — מופיע ברשימת הגיבויים, ואפשר לשחזר ממנו את התיקייה לגיטהאב
  דרך הבוט. ``metadata.json`` מתווסף בשכבת האחסון, כי רשימת הגיבויים נבנית
  מקריאתו.

שם הקובץ
~~~~~~~~~
ברירת המחדל היא שם התיקייה שנארזה (למשל ``logo-designer.zip``). הבוט מציע
אותה ומאפשר לבחור שם אחר; בבחירת "שם אחר" שולחים את השם בהודעה, בלי הסיומת
``.zip``. שמות בעברית נתמכים; תווים שאינם חוקיים בשם קובץ מוחלפים במקף.

מגבלות
-------
- מגבלות גודל/כמות קבצים בהתאם להגדרות GitHub ושירות ההורדה.
- קבצים שחורגים ממגבלת הגודל לקובץ בודד מדולגים, וכך גם קבצים שמעבר לתקרת
  הכמות או הגודל הכולל של הארכיון. שני סוגי הדילוג נספרים בנפרד ומדווחים —
  גם במסך הבחירה וגם בכיתוב הקובץ. הסינון הוא לפי גודל וכמות בלבד, לא לפי
  סוג הקובץ.
- אם *כל* הקבצים דולגו, הבוט אומר זאת במפורש ולא מציע לשמור ארכיון ריק.

הודעות נפוצות
--------------
- שגיאת הרשאות (ריפו פרטי בלי טוקן) – נדרש ``GITHUB_TOKEN`` תקין.
- חריגה ממגבלות קצב – נסו שוב מאוחר יותר.
- ``⌛ הקובץ פג`` – עברה שעה מהאריזה בלי לבחור יעד; אפשר לארוז שוב.
