שיתוף קוד (חשוב)
=================

מה זה עושה?
------------
כפתור "🔗 שתף קוד" מאפשר ליצור שיתוף מהיר של קובץ קוד דרך GitHub Gist או Pastebin.
השיתוף נוצר לפי מזהה הקובץ במסד (ObjectId), כך שתמיד משתף את התוכן העדכני ביותר.

איפה הכפתור מופיע?
-------------------
- בתפריט פריט קובץ לפני "הצג קוד".
- בתוך תצוגת "הצג קוד" של הקובץ.
- בהודעת ההצלחה לאחר שמירת קובץ (גם בהדבקת קוד וגם לאחר העלאת קובץ מצורף).

איך זה עובד (זרימה)
--------------------
1. לוחצים על "🔗 שתף קוד".
2. נפתח תפריט בין שני שירותים: "🐙 GitHub Gist" או "📋 Pastebin".
3. **Gist:** אם בחרת ב-GitHub Gist ולא חיברת את חשבון ה-GitHub שלך, הבוט מבקש להתחבר דרך תפריט ראשי ← 🐙 GitHub. ה-Gist ייווצר תחת החשבון שלך, כך שהוא נשאר שלך ומופיע ברשימת ה-Gists שלך.
4. לאחר בחירה, הבוט מעלה את התוכן לשירות ומחזיר קישור שיתוף.
5. ניתן לבטל בכל רגע על ידי כפתור "❌ ביטול" בתפריט.

דרישות (Prerequisites)
------------------------
**GitHub Gist:**
- חיבור חשבון GitHub אישי דרך הבוט (תפריט ראשי ← 🐙 GitHub).
- ה-Gist ייווצר תחת החשבון האישי שלך, לא תחת חשבון המערכת.
- ללא חיבור, תופיע הודעה עם הנחיה להתחבר או לבחור ב-Pastebin.

**Pastebin:**
- ``PASTEBIN_API_KEY`` – נדרש בסביבת הריצה (אין צורך בחיבור אישי).

מגבלות והתנהגות
----------------
- השיתוף מתבצע לפי ObjectId; אם אין מזהה זמין, הבוט יתריע.
- תוכן ריק/חסר יגרום לביטול השיתוף עם הודעת שגיאה ברורה.
- ייתכנו מגבלות גודל בצד השירותים (Gist/Pastebin) – במקרים כאלו תוצג הודעת כשל.

הודעות הצלחה/שגיאה
--------------------
- הצלחה: קישור ישיר חוזר בהודעה (כולל שם הקובץ).
- שגיאה: הודעה ידידותית, כולל הסבר אפשרי (למשל חיסרון חיבור GitHub לשיתוף Gist).

Troubleshooting קצר
-------------------
- **Gist לא עובד?** ודא שחיברת את חשבון ה-GitHub שלך דרך תפריט ראשי ← 🐙 GitHub. ה-Gist נוצר תחת החשבון שלך ודורש הרשאות מתאימות.
- **Pastebin לא עובד?** ודא ש-``PASTEBIN_API_KEY`` הוגדר בסביבת הריצה.
- בדקו שהתוכן אינו ריק ושקובץ באמת קיים למשתמש הנוכחי.
- אם שירות חיצוני מחזיר שגיאה זמנית – נסו שוב מאוחר יותר.
